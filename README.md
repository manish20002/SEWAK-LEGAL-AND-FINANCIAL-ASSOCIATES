# Sewak Legal & Financial Associates LLP

Multi-page Vue 3 and Vite website for Sewak Legal & Financial Associates LLP.

## Local development

```sh
npm ci
npm run dev
```

Run `npm run build` to type-check and create the production site in `dist`.

## GitHub Pages

The `main` branch is built and deployed automatically by `.github/workflows/pages.yml`.
The website is published at:

https://manish20002.github.io/SEWAK-LEGAL-AND-FINANCIAL-ASSOCIATES/
