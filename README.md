# Sewak Legal and Financial Associates LLP - Website

Welcome to the official repository for the website of **Sewak Legal and Financial Associates LLP**, a premier multidisciplinary corporate advisory firm based in Hyderabad, India. 

The live website can be viewed here: [https://manish20002.github.io/SEWAK-LEGAL-AND-FINANCIAL-ASSOCIATES/](https://manish20002.github.io/SEWAK-LEGAL-AND-FINANCIAL-ASSOCIATES/)

## 🏢 About the Firm
Sewak Legal and Financial Associates LLP, spearheaded by founder Amit Marda, bridges the gap between complex regulatory frameworks and seamless business operations. The firm provides integrated solutions across:
*   **Enforcement Directorate (ED) & Economic Offences:** PMLA & FEMA defense, asset attachment representation.
*   **Taxation & GST Compliance:** ITC optimization, DGGI survey support, and litigation.
*   **Commercial Litigation:** MSME debt recovery and contract enforcement.
*   **Financial Operations:** ERP-driven bookkeeping and internal audits.

## 💻 About this Project
This repository contains the front-end source code for the firm's official website. It is designed to be fast, responsive, and professional, reflecting the firm's core values of integrity and precision. 

### Tech Stack
*   **HTML5** for semantic structure.
*   **CSS3** (Tailwind CSS / Custom Styles) for a modern, responsive corporate UI design.
*   **JavaScript (Vanilla)** for mobile navigation and interactive elements.
*   **GitHub Pages** for deployment and hosting.

## 📂 Repository Structure
*   `index.html` - The main landing page / Home.
*   `about.html` - Firm history, mission, and leadership (Amit Marda).
*   `services.html` - Detailed breakdown of tax, legal, and financial services.
*   `work-projects.html` - Overview of notable engagements, including ED and PMLA cases.
*   `contact.html` - Contact information and inquiry form.
*   `/css` - Stylesheets.
*   `/images` - Logos and visual assets (including `logo.jpeg`).
*   `/js` - Interactive scripts.

    ```
2.  **Navigate to the project directory:**
    ```bash
    cd SEWAK-LEGAL-AND-FINANCIAL-ASSOCIATES
